What AudioKit is

AudioKit is an API for analysing and processing audio. It measures tracks (loudness, tempo, key, fingerprint, tags and similar), and it can transcode, preview and normalize audio and separate it into stems. The operations and how to call them are in the docs and the public API contract.

AudioKit is in beta. Features, prices and limits can change as it grows.
